# Einheit 1: Verständnisfragen

## Was ist der Unterschied zwischen Capacitor und Cordova?

Capacitor und Cordova machen aus Web-Apps mobile Apps.
Capacitor ist moderner und wird besonders bei Ionic verwendet. Cordova ist älter.

## Was macht ein ORM wie Sequelize, und wofür braucht man zusätzlich die sequelize-cli?

Sequelize ist ein ORM. Damit kann man in JavaScript einfacher mit einer Datenbank arbeiten, ohne ständig SQL schreiben zu müssen.
Die sequelize-cli hilft z. B. beim Erstellen und Verwalten von Migrationen und Models.

## Was unterscheidet npm install von npx beim Ausführen eines Pakets?

npm install installiert ein Paket im Projekt.
npx führt ein Paket bzw. dessen Befehl aus.

## Was ist REST, und warum passt das Konzept zu einer Client-Server-Architektur wie Ionic-App und Node-Backend?

REST ist eine Art, wie Client und Server über HTTP-Anfragen Daten austauschen.
Die Ionic-App kann z. B. Daten anfragen oder senden und das Node-Backend verarbeitet diese und antwortet.
